## 1. สินค้าคืออะไร (One-Liner)

> **"หนังสือดวงส่วนตัว 25 บท ที่บอกว่าดวงคุณควรลงทุนอะไร ยังไง เมื่อไหร่ — คำนวณจากตำราดวงจีน 60 กะจื่อ ไม่ใช่ดวงเดา"**

ผู้ใช้กรอก วัน/เวลา/สถานที่เกิด → ระบบคำนวณดวง (deterministic engine จาก bazi-sft-dataset) → สร้าง **หนังสือส่วนตัว (PDF/DOCX) 25 บท** ครอบคลุม: ธาตุการเงิน → เซกเตอร์หุ้นที่ใช่ → สินค้า/ตลาดที่เหมาะ (รวม forex/คริปโต) → สไตล์ระยะสั้น/ยาว → **ไทม์ไลน์ลงทุนทั้งชีวิต** → สิ่งต้องห้าม → เสริมดวงการเงิน

## 2. หลัก Hormozi ที่ใช้ — จับเข้า Value Equation

### 2.1 Value Equation: V = (Dream Outcome × Likelihood) / (Time Delay × Effort)

| ตัวแปร | สินค้าเราทำอะไร | วิธีเพิ่ม/ลด |
|---|---|---|
| **Dream Outcome** (ผลลัพธ์ฝัน) | "ลงทุนถูกทาง ถูกจังหวะ ตามพรหมลิขิต — ไม่พลาดจังหวะรวย ไม่โดนจังหวะเจ๊าะ" | เพิ่ม: บอกชัดว่า "ช่วงอายุ 32–37 คือจังหวะทองของดวงคุณ" |
| **Perceived Likelihood** (โอกาสเป็นจริง) | อิงตำราดวงจีน 60 กะจื่อ + ซินแสตรวจทาน + engine deterministic (รันซ้ำได้ผลเดิม) | เพิ่ม: ตัวอย่างดวงจริง 6 ดวง + ตราประทับ "คำนวณจากตำรา" |
| **Time Delay** (เวลารอ) | **ได้ทันที** หลังกรอกข้อมูล (< 2 นาที generate) | ลด: ไม่ต้องรอซินแสคิวแน่น |
| **Effort** (ความพยายาม) | กรอก วัน/เวลา/สถานที่เกิด เท่านั้น | ลด: ไม่ต้องรู้ศัพท์โหร ไม่ต้องอ่านตำรา |

### 2.2 Grand Slam Offer — ต่อยอดมูลค่าเป็นกอง (Offer Stacking)

```
แกนกลาง: หนังสือดวงนักลงทุน 25 บท (ส่วนตัว 1:1)
+ โบนัส 1: ปฏิทินมงคลการเงินรายเดือน 12 เดือน (PDF)
+ โบนัส 2: เช็กลิสต์ "เซกเตอร์หุ้นตามธาตุ" 1 หน้า (เอาไปใช้ที่ตลาดได้เลย)
+ โบนัส 3: Excel จัดพอร์ตตามธาตุ (กรอกเงิน → ได้สัดส่วนธาตุ)
+ โบนัส 4: คลิปอ่านเล่ม 30 นาที (วิธีใช้ไทม์ไลน์)
+ โบนัส 5: เข้ากลุ่ม LINE VIP ถาม-ตอบ 1 เดือน
```
→ ราคารวมที่ "รู้สึกว่าคุ้มเกินราคา" (Hormozi: มูลค่าที่รับรู้ ≥ 10× ราคา)

### 2.3 PAS — Problem / Agitate / Solve (หน้า Landing)

- **Problem**: คนไทย 80% ลงทุนโดยไม่รู้ "ดีเอ็นเอการเงิน" ของตัวเอง → ซื้อตามกระแส ตามข่าว ตามเพื่อน → ซื้อหุ้นที่ธาตุพิฆาตดวง ซื้อตอนจังหวะเจ๊าะ → ขาดทุน เก็บเงินไม่อยู่
- **Agitate**: ผิดจังหวะครั้งเดียว = เงินหลายปีหาย; "ดวงบอกได้ว่าช่วงไหนห้ามเสี่ยง" — แต่ไม่มีใครเคยแปลตำราให้คุณเป็นภาษาเงิน
- **Solve**: หนังสือดวงนักลงทุน — 25 บทที่แปล "ตำรา 60 กะจื่อ" เป็นคำสั่งลงทุนที่ทำตามได้ทันที

### 2.4 Value Ladder — บันไดความละเอียด 6 ชั้น (ฟรี → แพงสุด)

> หลัก Hormozi: ขาย "ก้าวถัดไป" ให้คนที่ได้ของฟรีไปแล้ว — แต่ละชั้นเพิ่มความละเอียดขึ้นหนึ่งระดับ
> (ธาตุ → เซกเตอร์ → กลุ่มหุ้น → **หุ้นรายตัว** → รายเดือน → ตัวต่อตัว)

| ชั้น | สินค้า | ความละเอียด | ราคา |
|---|---|---|---|
| 1. **Lead Magnet** | **"คุณเป็นนักลงทุนธาตุไหน?"** (รายงานฟรี ~8 หน้า) | **ระดับบุคคล**: ธาตุการเงิน + **การ์ดตัวตนนักลงทุน (1 ใน 15 แบบ)** + "คุณต้องลงทุนแบบนี้" + หุ้นตัวอย่าง 2–3 ตัว + **CTA เข้ากลุ่ม LINE รับ "10 หุ้นแรกที่เหมาะกับดวงคุณ"** | **ฟรี** (แลก LINE/email) |
| 2. **Tripwire** | "ดวงการเงินปีนี้" | ระดับเซกเตอร์: เซกเตอร์ที่ใช่ + ปีนี้รุก/รับ | ฿199 |
| 3. **Core เริ่มต้น** | หนังสือดวงนักลงทุน **ฉบับเซกเตอร์** | ระดับกลุ่มหุ้น: 20 เซกเตอร์ + หุ้นตัวอย่าง 5–10 ตัว/เซกเตอร์ (ระบุชื่อ พร้อมเหตุผลสั้น) + ไทม์ไลน์วัยจรทั้งชีวิต | ฿990 |
| 4. **Core กลาง** | หนังสือ **ฉบับหุ้นรายตัว (ไทย)** | **ระดับหุ้น**: 100+ หุ้นไทย รายตัวมี verdict + ธาตุ + เหตุผล + ไทม์ไลน์ + เช็กลิสต์ 60 ข้อ | ฿2,490 |
| 5. **Core สูง** | หนังสือ **ฉบับหุ้นทั่วโลก** ⭐ | ฉบับไทย + **8 ตลาดโลก** (จีน/เวียดนาม/ญี่ปุ่น/สหรัฐฯ/แคนาดา/ออสเตรเลีย/เกาหลีใต้/อินเดีย) — ทุกตลาดมี "ธาตุตลาด" (ทิศ→ธาตุ) + ดัชนี/ETF/หุ้นรายตัว verdict + สินค้าโลก (ทอง/น้ำมัน/คริปโต) | ฿4,990 |
| 6. **Profit Maximizer** | **VIP รายเดือน** | ฉบับทั่วโลก + อัปเดตทุกเดือน (ดวงเดือนหน้า + เตือนจังหวะ + หุ้นเข้า-ออกตามวัยจร) + กลุ่ม LINE ถาม-ตอบ | ฿790/เดือน หรือ ฿6,990/ปี |
| 7. **Premium** | **ฉบับซินแสตัวต่อตัว** | เล่มทั่วโลก + ปรึกษา 1 ชม. (เจาะพอร์ตจริง ถามได้ทุกตัว/ทุกตลาด) + ปรับ watchlist ส่วนตัว | ฿12,900 |

> **กลยุทธ์ราคา**: ชั้น 3 (฿990) = "ไม่แพงเกินไป กล้าลอง" · ชั้น 4 (฿2,490) = สินค้าหลัก margin สูง · **ชั้น 5 (฿4,990) = จุดขาย "ทั่วโลก" — เพิ่มตลาด = เพิ่มราคา** · ชั้น 6–7 = จับลูกค้าที่จริงจัง ต่างกันที่ "ความละเอียด + การต่อเนื่อง" ไม่ใช่แค่ราคา

### 2.5 Risk Reversal (กลบความเสี่ยงฝั่งคนซื้อ)

> "ถ้าอ่านครบ 25 บทแล้วรู้สึกว่า **ไม่ตรงกับชีวิตการเงินของคุณเลย** — ส่งมาบอกเรา เราปรับดวงให้ใหม่ฟรี หรือคืนเงินเต็มจำนวน ภายใน 7 วัน"

(ระวังข้อกฎหมาย: ใช้ถ้อยคำ "แนวโน้มตามดวง ไม่ใช่การันตีผลตอบแทน" ในหน้าซื้อขายเสมอ)

## 7.1 ระบบ "หุ้นรายตัว" (Stock-Level Engine) — จุดขายฉบับ ฿2,990+

### 7.1.1 หลักการ: ธุรกิจของหุ้น → ธาตุ → เทียบกับดวง

```
หุ้น X (เช่น KBANK ธนาคารกสิกรไทย)
  └─ ธุรกิจหลัก: ธนาคาร/สินเชื่อ/การเงิน  → ธาตุ น้ำ (หลัก) + ดิน (สาขา/สินเชื่อบ้าน)
       (อ้างอิง career-business.txt: น้ำ = การเงิน การธนาคาร สินเชื่อ นายหน้า)
  └─ เทียบกับดวง: useful god ของคุณ = [น้ำ, ทอง]
       → KBANK ธาตุน้ำ = ตรง useful → ✅ เหมาะ ระดับ "ดีมาก"
       → เหตุผล: "ประกอบธุรกิจธนาคาร การเงิน (ธาตุน้ำ) ซึ่งเป็นธาตุที่ดวงของคุณต้องการ"
```

### 7.1.2 คลังข้อมูลหุ้น (`data/stocks/thailand.json`)

แต่ละตัวมีโครงสร้าง:

```json
{
  "ticker": "KBANK",
  "name": "ธนาคารกสิกรไทย",
  "sector": "ธนาคาร",
  "business": "ธนาคารพาณิชย์ สินเชื่อ การเงิน รายย่อย-องค์กร",
  "elements": ["น้ำ", "ดิน"],
  "primaryElement": "น้ำ",
  "market": "SET",
  "tier": "SET50"
}
```

- **แหล่งข้อมูล**: SET Industry Group (ธนาคาร/พลังงาน/อสังหา/เทค/เกษตร/อาหาร/ขนส่ง/สื่อ...) + คำอธิบายธุรกิจจากงบ 56-1 → map เป็นธาตุด้วยกฎคำสำคัญ (keyword rules) แล้ว **ซินแส/ผู้เชี่ยวชาญตรวจทาน** (เพราะต้องแม่น ไม่เดา)
- **ขอบเขตเริ่มต้น**: ~100–150 ตัว SET50/SET100 + กองทุน/ETF + สินค้าโลก (ทองคำ/น้ำมัน/คริปโต — map ธาตุเอง)

### 7.1.3 กฎการให้ verdict (score ต่อหุ้น)

```
score = 0
ถ้า primaryElement ∈ usefulGod       → +3  (ดวงต้องการ)
ถ้า primaryElement ∈ tableB อันดับ 1  → +2  (ตาราง B บอกควรทำ)
ถ้า primaryElement ∈ tableB อันดับ 2+ → +1
ถ้า primaryElement == ธาตุลาภ (财)   → +2  (ดาวเงินโดยตรง)
ถ้า primaryElement ∈ avoidElements   → -4  (ธาตุพิฆาตดวง = ห้ามเด็ดขาด)
ถ้า secondaryElement ∈ usefulGod     → +1

verdict:
  score ≥ 4  → "เหมาะมาก ✅✅" (ลงทุนได้ เป็นแกนพอร์ต)
  score 2–3  → "เหมาะ ✅" (เข้าพอร์ตได้)
  score 1    → "กลาง 🟡" (ไม่ผิด ไม่โดดเด่น)
  score ≤ 0  → "ควรเลี่ยง ⛔" (ธาตุไม่ตรง / ตรงธาตุต้องห้าม)
```

### 7.1.4 หน้าแสดงผลรายหุ้น (ในเล่ม ฉบับ ฿2,990)

```
┌──────────────────────────────────────────────┐
│ KBANK — ธนาคารกสิกรไทย        ธาตุ: น้ำ (+ดิน) │
│ ธุรกิจ: ธนาคาร สินเชื่อ การเงิน               │
│                                              │
│ ✅ เหมาะมาก — ธาตุน้ำตรงกับธาตุที่ดวงต้องการ   │
│ เหตุผล: ประกอบธุรกิจการเงิน-ธนาคาร (ธาตุน้ำ)  │
│ ซึ่งเป็นธาตุส่งเสริม/ธาตุลาภของดวงคุณ          │
│                                              │
│ จังหวะ: วัยจรปัจจุบัน (ธาตุน้ำ) กำลังหนุน →   │
│ ช่วงนี้เข้าสะสมได้ตามจังหวะ                   │
│ ⚠️ หมายเหตุ: ดูไทม์ไลน์บท 16 ก่อนตัดสินใจ     │
└──────────────────────────────────────────────┘
```

- เรียงลำดับ: **เหมาะมาก → เหมาะ → กลาง → ควรเลี่ยง** (คนซื้อเห็นของดีก่อน)
- มี "watchlist ส่วนตัว" (ฉบับ VIP): หุ้นที่เหมาะสุด 10–20 ตัวของดวงนี้
- **ทุกหน้า/ทุก verdict มี disclaimer กำกับ** (หัวข้อ 7.2)

### 7.1.5 ตลาดหุ้นทั่วโลก (Global Markets) — จุดขายฉบับ ฿4,990

**หลักการ**: ไม่เหมารวมทั้งตลาด — **ทุกตลาดต้องแยกหุ้นรายตัว** เช่นเดียวกับไทย:

```
🇨🇳 ตลาดจีน (ธาตุตลาดจากทิศ = น้ำ)   ← แค่ "ภาพรวมประเทศ" ใช้อ้างอิงบท 8
  ├─ BABA (Alibaba)    ธุรกิจ: อีคอมเมิร์ซ/คลาวด์     → ธาตุ ทอง  → verdict รายตัว
  ├─ 601398 (ICBC)     ธุรกิจ: ธนาคาร               → ธาตุ น้ำ  → verdict รายตัว
  ├─ 600519 (Kweichow) ธุรกิจ: เหล้าองุ่นขาว/อาหาร   → ธาตุ น้ำ  → verdict รายตัว
  ├─ 300750 (CATL)     ธุรกิจ: แบตเตอรี่/พลังงาน     → ธาตุ ไฟ  → verdict รายตัว
  └─ ... (15–30 ตัว/ตลาด ตาม size + ความนิยมนักลงทุนไทย)
```

> ⚠️ **ธาตุตลาด (ทิศ) = ใช้กับ verdict "ภาพรวมประเทศ" ในบท 8 เท่านั้น**
> **verdict ของทุกหุ้น = ธาตุธุรกิจของบริษัท (ระบบ 7.1.3 เดิม) เสมอ** — ไม่มี "หุ้นจีนทุกตัวเป็นธาตุน้ำ"

**ตารางทิศ-ธาตุ (จากระบบเดิม)**: ไม้=ตะวันออก · ไฟ=ใต้ · ดิน=ตะวันตกเฉียงใต้/ตะวันออกเฉียงเหนือ · ทอง=ตะวันตก · น้ำ=เหนือ

**8 ตลาดเป้าหมาย (ธาตุตลาด = ทิศจากไทย ใช้ในบท 8 เท่านั้น):**

| ประเทศ/ตลาด | ดัชนีหลัก | ทิศจากไทย | ธาตุตลาด (ภาพรวม) | หุ้นรายตัวที่คัด (ตัวอย่าง) |
|---|---|---|---|---|
| 🇨🇳 จีน | SSE/Hang Seng | เหนือ | **น้ำ** | Alibaba(ทอง), Tencent(ทอง), CATL(ไฟ), ICBC(น้ำ), Kweichow(น้ำ) |
| 🇻🇳 เวียดนาม | VNINDEX | ตะวันออกเฉียงใต้ | **ไม้** | VCB(น้ำ), VNM(น้ำ/ไม้), VHM(ดิน), FPT(ทอง), MWG(น้ำ) |
| 🇯🇵 ญี่ปุ่น | Nikkei 225 | ตะวันออกเฉียงเหนือ | **ดิน** | Toyota(ทอง), Sony(ทอง), Nintendo(ทอง), MUFG(น้ำ), Fast Retailing(ไม้) |
| 🇺🇸 สหรัฐฯ | S&P 500/Nasdaq | ตะวันออก (ข้ามมหาสมุทร) | **ไม้** | Apple(ทอง), NVDA(ทอง), JPM(น้ำ), XOM(ไฟ), COST(น้ำ) |
| 🇨🇦 แคนาดา | TSX | ตะวันออกเฉียงเหนือ | **ดิน** | RBC(น้ำ), Shopify(ทอง), Enbridge(ไฟ), Barrick(ทอง), CN Rail(ทอง/ไม้) |
| 🇦🇺 ออสเตรเลีย | ASX 200 | ใต้ | **ไฟ** | BHP(ทอง), CBA(น้ำ), CSL(น้ำ/ไฟ), Woodside(ไฟ), Telstra(ทอง) |

**วิธีเพิ่มมูลค่าในเล่มฉบับทั่วโลก:**

## 7.3 Lead Magnet ฟรี — "คุณเป็นนักลงทุนธาตุไหน?" (เครื่องจักรเก็บ LINE)

### 7.3.1 หลักการ (Hormozi: ของฟรีต้อง "ว้าว" จนนึกไม่ออกว่าทำไมฟรี)

> ของฟรีไม่ใช่ "1 หน้ากระดาษ" — แต่เป็น **รายงาน 8 หน้า ที่พูดถึง "ตัวฉัน" โดยตรง**
> จุดจบของรายงาน = **CTA เข้ากลุ่ม LINE** เพื่อรับของต่อ (ไม่ใช่แค่กรอก email ทิ้ง)

### 7.3.2 โครงสร้างรายงานฟรี 8 หน้า

| หน้า | เนื้อหา | หน้าที่ (Hormozi) |
|---|---|---|
| 1 | ปก: "คุณเป็นนักลงทุนธาตุไหน?" + ชื่อเจ้าชะตา | สะกดความสนใจ (Attention) |
| 2 | ธาตุการเงินของคุณ (ดิถี/กำลัง/ธาตุลาภ) แบบการ์ดสวยงาม | Personalization — "มีแค่ฉันคนเดียว" |
| 3 | **การ์ดตัวตนนักลงทุน (1 ใน 15 แบบ)** — ชื่อ + คำอธิบาย + จุดแข็ง/จุดอ่อน | ตัวตน (Identity) — "นี่คือฉัน!" |
| 4 | "คุณต้องลงทุนแบบนี้" — สไตล์ที่เหมาะ (รุก/รับ/เก็งกำไร/ถือยาว) + สิ่งที่ควรเลี่ยง | คำแนะนำแรก — มีค่าทันที |
| 5 | หุ้น/เซกเตอร์ตัวอย่าง 2–3 ตัว ที่เหมาะกับดวงคุณ (พร้อมเหตุผลสั้น) | ตัวอย่าง (Proof of value) |
| 6 | "10 หุ้นแรกที่เหมาะกับดวงคุณ" — **เบลอ/ตัดกลาง** + ข้อความ "ดูต่อในกลุ่ม LINE" | เหลือค้าง (Open loop) |
| 7 | ตัวอย่างหน้าจากเล่มเต็ม (บทไทม์ไลน์) — teaser ฉบับ ฿990+ | อวดสินค้าแพง |
| 8 | CTA: ปุ่ม QR LINE + "กดเข้ากลุ่มรับ 10 หุ้น + ปฏิทินรายเดือนฟรี" | Conversion |

### 7.3.3 ระบบการ์ดตัวตนนักลงทุน 15 แบบ (5 ธาตุ × 3 กำลัง)

> ฟีเจอร์เด่นของรายงานฟรี: **ทุกคนได้ "การ์ดตัวตน" ของตัวเอง** → อยากแชร์/อยากรู้จักตัวเอง → แชร์ลงโซเชียล = การตลาดฟรี (viral)

| ธาตุ | ดวงอ่อน | ดวงสมดุล | ดวงแข็ง |
|---|---|---|---|
| **ไม้** (เติบโต) | "ต้นกล้า" — สะสมทีละนิด เน้นกองทุน/ระยะยาว | "ไม้ใหญ่" — ผสมยาว+เก็งกำไรบางส่วน | "ป่าไม้" — ขยายหลายทาง กล้าเสี่ยง |
| **ไฟ** (เก็งกำไร) | "ประกายไฟ" — เริ่มติดไฟ ระวังแรงไม่พอ | "เปลวไฟ" — เก็งกำไรตามจังหวะ | "ดวงอาทิตย์" — เทรดหนัก ร้อนแรง |
| **ดิน** (มั่นคง) | "ดินทราย" — ออมก่อน ปลอดภัยไว้ก่อน | "ทุ่งนา" — อสังหา+ปันผล+เก็บออม | "ภูเขา" — อสังหาขนาดใหญ่ ถือยาว |
| **ทอง** (แม่นยำ) | "ทองคำแท่ง" — โลหะมีค่า ปลอดภัย | "เหล็กกล้า" — เทค+ทองผสม วางแผนแม่น | "เพชร" — หุ้นเทครายตัว กล้าได้กล้าเสีย |
| **น้ำ** (หมุนเวียน) | "หยดน้ำ" — ออมรายเดือน สม่ำเสมอ | "แม่น้ำ" — การเงิน+เทรดตามกระแส | "มหาสมุทร" — ทุกจังหวะ ทุกตลาด |

## 8. Roadmap (สั่งทำ)

1. **Phase 1 — Knowledge**: ingest Source4 + career-business เป็น JSON/TS + สร้างตารางใหม่ (เซกเตอร์/สินค้า/ตลาด/สไตล์)
2. **Phase 1.5 — คลังหุ้นไทย**: สร้าง `stocks/thailand.json` (~100 ตัว SET50/100) — map ธุรกิจ→ธาตุ + ซินแสตรวจทาน
3. **Phase 1.6 — คลังหุ้นโลก**: สร้าง `markets/world-map.ts` (8 ประเทศ→ทิศ→ธาตุ) + `stocks/global.json` (ดัชนี/ETF/หุ้นเด่น 5–10 ตัว/ตลาด) + `stocks/commodities.json`
4. **Phase 2 — Core engine**: investor-types → investor-data → investor-guide (บท 1–10) + `stock-classifier.ts` (score/verdict รายหุ้น + 2 ชั้น: ตลาด/หุ้น) + `investor-persona.ts` (การ์ด 15 แบบ) + tests
5. **Phase 2.5 — Lead Magnet**: `lead-magnet.ts` (รายงานฟรี 8 หน้า) — เอาไปเปิดเก็บ LINE ได้ก่อนขาย
6. **Phase 3 — Timeline**: buildInvestorTimeline (บท 16–19) — จุดขายหลัก
7. **Phase 4 — เล่มเต็ม**: templates ครบ 25 บท + หน้า verdict รายหุ้น (ไทย + 8 ตลาดโลก) + แผนที่โลกตามธาตุ + **disclaimer ทุกจุด** + export docx/pdf
8. **Phase 5 — หน้าเว็บ**: landing (PAS) + ฟอร์ม + lead magnet ฟรี + checkout (checkbox ยืนยัน)
9. **Phase 6 — ขาย**: tripwire ฿199 → ฉบับเซกเตอร์ ฿990 → ฉบับหุ้นไทย ฿2,490 → **ฉบับทั่วโลก ฿4,990** → VIP รายเดือน → ปรึกษา

**MVP แนะนำ**: Phase 1–2 + ฉบับเซกเตอร์ ฿990 (ขายได้ก่อน) → ต่อยอดหุ้นรายตัว (ไทย ฿2,490) → เติมตลาดโลก (฿4,990)
